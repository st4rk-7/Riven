# Original proposal reference

The original title is **Multi-Tenant Automated Competitor Tracking and Analysis System for Online Retailers** (EC5406). The reference PDF states a submission date of 25 September 2026. Submission is reported by the team; the available reference has blank client-signature fields.

The proposal describes a retailer-facing multi-tenant system with two source platforms, background price/availability/offer collection, variant comparisons, timestamped history, charts/tables, notifications, tiers, and administration. The [working SRS](requirements.md) preserves this product direction and exposes unresolved details.

## Important clarifications, not silent changes

- “Real-time” notifications must be reconciled with periodic collection and an agreed delay.
- Helping a retailer decide prices is not proof that automatic repricing is required.
- Cloud-based/scalable describes intended delivery, not current hosting or measured capacity.
- Two platforms remain proposed final scope; only Amazon is selected first, with access still unresolved.
- The proposal mentions push notifications; the initial channel remains to be confirmed, not silently replaced by email.
